# 🌍 Web Projects: Travel Landing Page & E-Commerce Platform

This repository contains two front-end web development tasks built using **HTML**, **CSS**, and **JavaScript**:

## ✨ Task 1: Travel Website Landing Page
A sleek and visually engaging landing page designed for a travel agency. It features:

- Hero section with a strong call-to-action
- Clean navigation
- Responsive design layout
- Smooth scroll and subtle animations

> Goal: To capture attention and spark wanderlust in one scroll.

## 🛒 Task 2: E-Commerce Platform (Frontend)
A responsive, user-friendly front-end layout for an e-commerce platform, including:

- Product listings with filter/sort options
- Shopping cart UI
- Basic interactivity using JavaScript
- Clean and structured CSS

> Goal: A functional, intuitive interface ready to plug into a backend system.
